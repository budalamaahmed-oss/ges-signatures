# Experts Gate by GES — proposed sitemap

The six pages that exist today are the spine. This document proposes the pages to build next, in priority order, with what each page is for and the content still needed from GES to build it well. Nothing here should be built with invented content; the "Needs" column is the ask.

Legend: **Live** = built · **P1** = build next · **P2** = once content exists · **P3** = later

## 1. Home — Live
Thesis, three disciplines, sequence, lifecycle, outcomes, selected work, ecosystem, presence, diagnostic CTA.
